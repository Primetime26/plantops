# Шаблон дефекта

- **ID / краткое название:**
- **Версия / commit / окружение:** ОС, Node, браузер, APP_MODE.
- **Severity / priority:** влияние и срочность отдельно.
- **Предусловия:** данные, статус, время, cookie-контекст без раскрытия самой cookie.
- **Шаги:** минимальная воспроизводимая последовательность.
- **Ожидалось:** ссылка на правило/кейс.
- **Фактически:** сообщение, HTTP, изменения объекта.
- **Повторяемость:** N попыток / N воспроизведений.
- **Доказательства:** screenshot, trace, очищенные логи/запросы.
- **Причина / исправление:** после диагностики.
- **Регрессия:** тест и фактический результат повторной проверки.
- **Статус / остаточный риск:** NEW / CONFIRMED / FIXED / VERIFIED / BLOCKED.

## Реальные наблюдения этой итерации

### PO-101 — Избыточное копирование временного хранилища

Обнаружен при измерении памяти новой реализации. Первоначальные лимиты30 сессий ×40 заявок с максимальными комментариями/историей; каждый tick делал structuredClone всего состояния. Нагрузочный прогон с heap160МБ завершился OOM. После устранения полных копий, но до пересмотра лимитов, измеренный RSS составил335,6МиБ — выше целевых256.

Исправление: транзакция копирует контейнеры коллекций и изменяемые записи; список/summary не загружает вложенную историю; карточка получает одну заявку. Публичные лимиты снижены до10 сессий и20 заявок. Runtime ограничивает V8 heap128МБ и semi-space4МБ. Повторный стресс-прогон: около151МиБ RSS на macOS/Node24, без Prisma. Регрессия: `scripts/measure-demo.mjs`, rollback/лимиты API. Контейнер Layero отдельно не измерялся.

### PO-102 — Пустой PATCH/reset конфликтовал с JSON-защитой

Выявлен при сверке реальных UI-запросов с middleware: прежний клиент отправлял ACK/reset без тела, а новый `req.is('application/json')` для запроса без тела возвращает false. Supertest-сценарии с `.send({})` этого расхождения не покрывали.

Исправление: общий клиент добавляет `{}` к мутациям без тела и отправляет JSON + custom header. Подтверждение инцидента и reset проверены в браузере; client.test.ts проверяет фактические параметры fetch. Полный браузерный регрессионный сценарий добавлен в Playwright. Его успешный автоматический прогон в этой среде пока не подтверждён.

### ENV-01 — Chromium не стартует в песочнице macOS

Запуск `npm run test:e2e`: четыре сценария остановлены до первого действия. Chromium: `MachPortRendezvous ... Permission denied`, сигнал SIGTRAP. Это ограничение тестовой среды, не доказательство дефекта UI и не PASS. Добавлен запуск Chromium в Ubuntu CI; CI ещё требуется выполнить после самостоятельного push. Через доступный in-app браузер проведён отдельный ручной smoke, указанный в отчёте.
