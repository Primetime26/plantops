# Приёмочный чек-лист

Отмечать при конкретном прогоне, не автоматически по наличию кода. Текущий отчёт — `../VERIFICATION.md`.

## Установка и данные

- [ ] Чистая установка npm ci и setup на целевой ОС.
- [ ] Повторный setup не дублирует и не сбрасывает активы.
- [ ] Local перезапуск сохраняет fault, ACK, заявки, комментарии и историю.
- [ ] Public Demo собирается и стартует без DATABASE_URL и БД.
- [ ] API и глубокие SPA-ссылки обслуживаются одним Express.

## Сценарий оператора

- [ ] Пять активов, обновления, дата и состояние API.
- [ ] Поиск/фильтры оборудования и журнала.
- [ ] Перегрев, давление, вибрация, комбинированный отказ.
- [ ] Нет вибрационного сценария у теплообменника.
- [ ] Один активный инцидент на параметр, эскалация без дубля.
- [ ] ACK не лечит оборудование; reset устраняет, сохраняя историю.
- [ ] Заявка создаётся, редактируется, комментируется, выполняется/отменяется.
- [ ] Нельзя завершить при аварии, без результата или из OPEN.
- [ ] Нельзя править закрытую заявку или потерять чужую версию.
- [ ] Аналитика и CSV отражают реальные накопленные данные.

## Public Demo и UX

- [ ] Два приватных браузерных контекста изолированы.
- [ ] Истёкшая cookie/перезапуск → новые данные и уведомление.
- [ ] Reset затрагивает только текущую сессию и требует подтверждения.
- [ ] 503, 429, offline и медленный первый запрос понятны пользователю.
- [ ] Скрытая/неактивная вкладка прекращает запросы; продолжение работает.
- [ ] 1440px/820px: таблицы доступны, нет перекрытий и переполнения страницы.
- [ ] Клавиатура, видимый focus, labels, Escape, disabled во время операции.
- [ ] Пользовательский HTML отображается текстом.
- [ ] Уведомление о симуляции и временном хранении видно.

## Выпуск

- [ ] TypeScript, unit/API, production build и форматирование проходят.
- [ ] Chromium E2E действительно выполнен, trace ошибок рассмотрен.
- [ ] Ресурсная проверка ниже целевого RSS; runtime не загружает Prisma.
- [ ] Нет .env, БД, секретов, node_modules и тестовых артефактов в Git.
- [ ] CI успешно выполнен после самостоятельного push.
- [ ] На Layero выбран Free, один root node_web, бесплатный адрес.
- [ ] HTTPS-cookie, холодный старт и фактическое поведение pod проверены на хостинге.
- [ ] Тариф и потребление сверены; платные зависимости отсутствуют.
