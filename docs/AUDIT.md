# Аудит перед доработкой (12 ноября 2026)

Сохранены React/Vite/TypeScript, Tailwind/shadcn Button, Recharts, Router, npm workspaces, Express, Prisma/SQLite и общие контракты. Существуют пять единиц оборудования, два независимых дефекта, транзакционное создание/эскалация/подтверждение/устранение инцидентов, фильтры, графики и аналитика. Production Express уже раздаёт frontend.

Выявлено: Prisma импортируется безусловно при старте; таймер обязателен; нет изоляции посетителей и лимитов истории; отсутствуют заявки/CSV/вибрационный сценарий/E2E. Клиентский timeout 10 секунд короче некоторых холодных стартов. Начальная ошибка API оставляет некоторые панели в неопределённой загрузке. Обновление продолжается в скрытой вкладке. Код расчёта зависит от Prisma-типов. Эти недостатки устраняются без замены работающего интерфейса и модели порогов.

План: (1) независимые domain-типы и Repository/Unit of Work; (2) Prisma и bounded memory адаптеры, сессии и request-driven clock; (3) заявки, версия записи, комментарии/аудит, CSV; (4) UX холодного старта, сброс и обслуживание; (5) unit/API/E2E и QA; (6) единый Node deploy, проверка памяти и инструкция Layero. Push и deploy не выполняются.
